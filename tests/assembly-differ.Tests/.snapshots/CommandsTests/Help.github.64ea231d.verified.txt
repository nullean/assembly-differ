Usage: assembly-differ github <repository> <commit> <path> --build <string> --artifacts <string> [options]

   Compares a new build with an older commit of a GitHub repository, built with the command you give.

Arguments:
  <repository>  The repository as owner/name.
  <commit>      The commit, branch or tag to build as the old version.
  <path>        The new build: a .dll or a directory.

Global options:
  -h, --help             Show help.

Options:
  --build <string>       [required] The command that builds the old commit, run in its checkout.
  --artifacts <string>   [required] Where the build leaves the assemblies, relative to the checkout.
  -t, --target <values>  [repeatable] Only compare these assemblies, by file name without extension. Repeat it for more than one.
  -f, --format <string>  The report: markdown, xml, asciidoc, github-comment or json. [default: markdown] [allowed: markdown|xml|asciidoc|github-comment|json]
  -o, --output <string>  A directory or file to write the report to, besides the console.
  --fail-on <string>     Exit with code 4 when the suggested version change is at least this: none (never), patch, minor or major. [default: none] [allowed: none|patch|minor|major]

Examples:
  assembly-differ github nullean/proc 0.13.0 src/Proc/bin/Release/netstandard2.0 --build "dotnet build -c Release" --artifacts src/Proc/bin/Release/netstandard2.0

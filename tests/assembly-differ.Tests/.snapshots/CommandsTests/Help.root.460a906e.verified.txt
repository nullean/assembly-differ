Usage: assembly-differ <namespace|command> [options]

 (default command)
   Compares every library project in the current directory with the latest release of its package. Runs when no command is given.

   It reads the one solution in the directory, or else the project files in it, and skips test projects and projects
   with IsPackable set to false. It compares each project's Release build, for its newest target framework, with the
   latest stable release of its package on the feeds your NuGet.config lists. It does not build: run
   dotnet build -c Release first, and a project without build output is skipped with a warning. A project whose
   package has no release yet is reported and skipped. It needs the .NET SDK, to read the projects.

Global options:
  -h, --help  Show help.
  --version   Show version.

Commands:
  files         Compares two local builds: dlls, directories of dlls, or .nupkg
                files.
  nuget         Compares two versions of a package; in a solution, the version
                your projects use with another.
  projects      Compares every library project in the current directory with the
                latest release of its package. Runs when no command is given.
  pull-request  Puts a report on the pull request a GitHub Actions run is for:
                the job summary, one comment kept up to date, and the release
                label for the suggested version change.
  release       Compares a new build with the release before it.
